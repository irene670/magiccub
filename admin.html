名畫方塊 後台

點這裡或拖曳圖片上傳
一次可選多張，每張圖片就是方塊的「一面」（3×3 九宮格）。會自動裁成正方形、縮成 600×600。

建立新方塊

點每一格選一張圖片；用 ↻ 調整方向。排法是方塊的展開圖：「上」的下緣接「前」的上緣，「下」的上緣接「前」的下緣，左、前、右、後由左到右繞一圈，四面的上緣都接「上」。

GitHub 連線（儲存圖片用）

圖片和方塊資料會存進 GitHub 專案 （gh-pages 分支的 library 資料夾），前台網站直接讀取。需要一組 GitHub「Fine-grained personal access token」，權限只要這個專案的 Contents：Read and write。這組 token 只存在這台裝置的瀏覽器裡。
